# Feature Finish

## 收尾清单

1. 汇总改动仓库和模块。
2. 汇总字段链路核对层级。
3. 汇总 Apifox 文档变化或无需变化原因。
4. 汇总 Maven 验证命令和结果。
5. 说明消费者影响和未联调风险。
6. 输出复盘沉淀建议：可复用结论、Agent 纠正点、验证配方候选、过时记忆和重复推理次数。
7. 默认下一步为 `【learn】<slug>`；没有可沉淀内容时也要说明原因。

## 交付格式

```markdown
## 改动范围

## 字段链路

## 验证结果

## 影响范围

## 未联调风险

## 复盘沉淀建议

## 下一步
```
