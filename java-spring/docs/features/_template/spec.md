# Spec: <功能标识>

## 用户故事

作为调用方，我希望获得准确、稳定、可追溯的后端接口能力，以便完成业务流程。

## 功能需求

| ID | 需求 | 优先级 |
|---|---|---|
| FR-1 | 后端返回字段必须来自明确数据源，并完成逐层赋值 | P0 |
| FR-2 | 外部接口契约变化必须同步文档和示例 | P0 |

## 验收场景

### 场景 1：主查询流程返回字段

- Given 数据源存在目标字段
- When 调用主查询接口
- Then 网关响应包含目标字段且值与数据源一致

### 场景 2：数据源为空

- Given 数据源字段为空
- When 调用主查询接口
- Then 响应字段按既有空值规则返回，不抛出异常
