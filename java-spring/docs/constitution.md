# 后端项目宪法

本文件适用于 Java 8、Spring、Maven 多模块后端项目。具体业务仓差异以 `.cursor/project-conventions.md` 为准。

## 不可违反原则

1. 领域真相优先落在领域仓，`HiStore-gw` 只承载鉴权、聚合、适配和端侧契约。
2. 字段和接口契约变更先看 `*-api`，业务规则看 `*-core`，数据库访问看 `*-dao`，启动配置看 `*-server`。
3. 新增或修改 DTO 字段必须核对完整赋值链路，包括下游返回对象、领域对象、Feign 或 Thrift 响应、网关聚合响应、Apifox 文档。
4. 新增字段默认补针对性测试，至少覆盖主查询或主提交流程。
5. Spring 托管类默认只保留一个生产构造器，测试便利不能反向推动生产类增加重载构造器。
6. Java 版本固定为 JDK 8，禁止使用高版本语法。
7. Maven 构建必须进入具体子仓，优先执行受影响模块的最小闭环验证。
8. 涉及权限、用户、店铺、共享契约的改动，交付时必须说明影响范围和未联调风险。
9. 涉及 `HiStore-gw` 外部接口契约变化，必须同步 Apifox 文档和 mock 示例；如果不更新，需要说明原因。
10. 注释、日志、交付说明必须使用 UTF-8 可正常显示的中文，不允许出现乱码、替代符和连续问号。

## 仓库职责

| 仓库 | 职责 |
|---|---|
| `HiStore-gw` | BFF、聚合接口、多端适配、Apifox 文档 |
| `HiStore-base` | 平台基础配置、用户、权限、店铺基础能力 |
| `HiStore-trade` | 商品、营销、购物车、预下单、交易前链路 |
| `HiStore-order` | 订单、支付、售后、履约、评论、状态流转 |
| `HiStore-report` | 统计报表、经营分析、导出 |
| `HiStore-starter` | 父 POM、公共 starter、基础设施组件 |
