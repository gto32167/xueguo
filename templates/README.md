# 模板说明

模板按通用研发节点分组。复制模板到项目空间后填写关键索引，不要把聊天全文、完整日志、凭据或大段代码复制进来。

| 目录 | 用途 |
|---|---|
| `requirements/` | 需求发现、当前基线、基线规格、变更单 |
| `tasks/` | 任务版本、仓库、分支、冲突和下一步 |
| `bugs/` | TAPD BUG 复现、回归测试和验证证据 |
| `releases/` | 选择性发布清单 |
| `coordination/` | 并行任务冲突登记 |
| `environments/` | 测试环境租约和部署版本 |
| `memory/` | 项目记忆、验证配方和工具候选 |
| `retrospectives/` | 任务完成后的复盘与自演进建议 |
| `status/` | 团队共同上下文、风险和待人工决策 |
