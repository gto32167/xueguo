# 项目空间

本目录用于保存跨账号、模型、会话和 Agent 的轻量任务索引。每个项目一个目录：`projects/<project-id>/`。

项目空间只保存需求基线、变更单、任务状态、关键决策、发布清单、验证证据索引和经过筛选的项目记忆，不保存聊天全文、构建日志、临时文件、凭据或完整代码副本。

## 1.1 推荐目录

- `memory/`：候选或已验证的领域规则、服务关系、常见遗漏、验证配方和工具候选。
- `retrospectives/`：任务完成后的复盘记录。
- `status/`：当前任务、待人工决策、风险、冲突和冻结发布索引。

记忆条目默认是 `CANDIDATE`，必须经过代码、测试或人工决策验证后才能晋级 `VERIFIED`；过时条目标记为 `DEPRECATED`，不得静默覆盖历史。

项目空间可以独立提交和升级。框架升级工具不会覆盖此目录。
